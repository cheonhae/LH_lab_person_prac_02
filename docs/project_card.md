# 팀 프로젝트 카드

| 항목 | 내용 |
|---|---|
| 주제 | 주간 민원대장 CSV를 넣으면 중복·빈칸 행을 사유와 함께 걸러 내고, 유형별·처리상태별 건수를 세어 "합계 = 전체 행 − 제외 행"을 스스로 확인하는 민원 집계 검증 웹앱 |
| 출발점 | 팀원 A의 PRD 메모(`docs/prd_memo.md`) — "엑셀 필터로 세다 보니 중복 접수·빈칸 행이 섞여 보고 수치가 자주 틀린다" |
| 검증 절차 | **계산** — `rules/aggregation_rules.md` 2절(중복·집계 항목·신청방법 대응표) 기준으로 세고, 웹앱 결과를 `scripts/aggregate.py` 출력·손 계산과 대조해 `check.md`에 남긴다 (제외 행 사유는 근거로 함께 남김) |
| 오늘 만들 것 | 여러 페이지 HTML 웹앱 — ① **집계 페이지**: CSV를 넣으면 유형별·처리상태별 건수표와 "합계 일치/불일치" 판정이 보인다 · ② **제외 행·근거 페이지**: 제외 행마다 원본행·사유·원본값 목록과 `excluded_rows.csv` 내려받기, 신청방법 비표준 표기를 바꾼 수정 행 목록이 보인다 |
| 만들지 않을 것 | 서버·로그인·DB / 실제 민원 자료(실명·연락처) 입력 / 차트·대시보드 / 보고서 문장 자동 작성 / 대장(`ledger.csv`) 수정·정합 기능 / 외부 라이브러리·외부 주소 사용 |
| 역할 | ① 팀원 A — PRD·Issue 정리와 범위 관리, 집계 페이지 개발 ② 팀원 B — 표본 CSV(정상·이상·함정) 준비와 결과 대조(`check.md`), 제외 행·근거 페이지 개발 |
| 리뷰 짝 | ①↔② (A가 만든 집계 페이지는 B가 표본 기대 결과로 검토하고, B가 만든 근거 페이지는 A가 PRD 기준으로 검토) |

## 메모

- 표본은 `inputs/m2/G-M2-01_민원대장_week1.csv` 열 구성(접수번호·접수일·신청방법·민원유형·적용공고·처리상태)을 따른 가상 자료로 만든다.
- 규칙에 없는 표기·경우가 나오면 웹앱이 임의로 처리하지 않고 `{확인 필요}`로 표시한다.
- 팀원 이름은 실제 이름으로 바꿔 적는다.
