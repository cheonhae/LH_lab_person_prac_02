## 2. 성공 시나리오 (PRD 5절)

| S | 넣는 것 | 화면에 보일 것 |
|---|---|---|
| S1 | 오류 없는 정상 표본 CSV를 넣는다 | "합계 일치", 경고 0건, 제외 0행이 보인다 |
| S2 | 한 구분의 항목 금액 하나를 바꾸고 빈칸·문자 숫자·중복 행을 하나씩 심은 이상 표본 CSV를 넣는다 | "합계 불일치"와 함께 어긋난 구분과 차이 금액(예: −500,000원)이 보인다 |
| S3 | S2와 같은 이상 표본 CSV를 넣는다 | 제외 3행이 행 번호·사유·원본 값과 함께 보이고, 정상 기준 재집계 총액과 근거 파일 세 개 내려받기 버튼이 보인다 |

## 3. 표본과 기대 결과

- 파일: `data/m5_sample.csv` (가상, 16건: 항목 12건 + 소계 3건 + 합계 1건. 열 `구분`·`항목명`·`집행금액`, 행 번호는 머리행을 빼고 1부터)
  - S1 정상 표본: `data/m5_sample_normal.csv` (가상, 15건: 항목 11건 + 소계 3건 + 합계 1건)
  - S2·S3 이상 표본: `data/m5_sample_error.csv` (가상, 18건: 항목 14건 + 소계 3건 + 합계 1건. 5행 문자 숫자 · 10행 중복(9행과 같음) · 12행 인쇄 금액 변경 · 14행 빈칸)
- 경계값: 3행 — 집행금액 `"1,500,000"`(따옴표 안 쉼표가 든 금액. 쉼표를 빼고 숫자로 읽어 포함해야 하며, 칸이 갈라지거나 문자 숫자로 제외되면 안 됨)
- 일부러 넣은 함정: 9행 — 중복(7행 `옥외,지하철 역사 포스터,1600000`과 모든 열이 같음)
- 기대 결과: S1 {경고 0건, 합계 일치, "잘못 잡음 0건" / S2 {제외 3행, 합계불일치, 놓침 0건} / S3 - 근거 파일 세 개 보여주기 및 내려받기 버튼
  - 함정(`data/m5_sample.csv`): "합계 일치". 전체 16행 = 포함 11행 + 제외 1행 + 보고서 행 4행(소계 3·합계 1). 경고 1건 = 제외 1행: 9행 · 중복(7행과 같음) · `옥외,지하철 역사 포스터,1600000`. 구분별 차이는 온라인·옥외·인쇄 모두 0원, 재집계 총액 16,400,000 = 보고서 총액. 3행(1,500,000)과 7행은 제외 목록에 없음(잘못 잡음 0건).
