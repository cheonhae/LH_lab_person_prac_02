# m5_1 — 화면 틀과 표본 넣기

## 제목
화면 틀과 표본 넣기

## 목적
`tools/m5_budget_check.html` 한 파일에 화면 ①~③의 틀을 만들고, CSV 파일을 고르면 그 행을 표로 보여 준다. 판정은 아직 하지 않는다.

## 완료 기준
| S | 사람이 화면에서 볼 것 |
|---|---|
| S1~S3 공통 준비 | 화면 ①에 고정된 정상 기준 3가지(빈칸·문자 숫자·중복 행)와 "가상 표본만 넣으세요" 안내가 보인다. |
| S1~S3 공통 준비 | `data/m5_sample.csv`를 고르면 표에 16행(행 번호·구분·항목명·집행금액)이 보인다. |
| S1~S3 공통 준비 | 3행 집행금액이 `1,500,000` 한 칸으로 보인다(따옴표 안 쉼표로 칸이 갈라지지 않음). |

## 범위 밖
- 이상 행 판정, 소계·총액 비교(m5_2)
- 근거 파일, localStorage 저장, JSON 백업, 오류 안내(m5_3)
- CSV 붙여 넣기·직접 입력(다음 버전)
