# m5_2 — MVP 판정

## 제목
MVP 판정: 이상 행 걸러내고 정상 기준 집계, 어긋난 곳 표시

## 목적
PRD 3.1절의 기능 1(이상 행 걸러내고 정상 기준 집계)과 기능 2(어긋난 곳 표시)를 만든다. 결과는 화면 ②에 보이고, 결과 위에 "담당 검토 후 확정"을 표시한다.

## 완료 기준
| S | 사람이 화면에서 볼 것 |
|---|---|
| S1 | 오류 없는 정상 표본 CSV를 넣으면 "합계 일치", 경고 0건, 제외 0행이 보인다. |
| S2 | 한 구분의 항목 금액 하나를 바꾼 표본 CSV를 넣으면 "합계 불일치"와 함께 어긋난 구분과 차이 금액이 보인다. |
| S3 (판정 부분) | 빈칸·문자 숫자·중복 행을 하나씩 심은 표본 CSV를 넣으면 제외 3행이 행 번호·사유·원본 값과 함께 보이고, 정상 기준 재집계 총액이 보인다. |
| 함정 | `data/m5_sample.csv`를 넣으면 `docs/m5_plan.md` 3절의 기대 결과(사람이 적음)대로 보인다. |
