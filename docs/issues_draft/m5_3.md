# m5_3 — 저장·오류 안내·다듬기

## 제목
근거 파일·저장·오류 안내·다듬기

## 목적
PRD 3.1절의 기능 3(집계 근거 파일 생성), 4절 저장(localStorage 키 `m5_budget_check` 하나와 JSON 백업 내보내기·가져오기), 잘못된 입력에 대한 안내를 만든다.

## 완료 기준
| S | 사람이 화면에서 볼 것 |
|---|---|
| S3 (근거 파일 부분) | 빈칸·문자 숫자·중복 행 표본을 넣은 뒤 화면 ③에서 집계 결과·제외 사유와 원본 값·실행 로그 세 파일을 내려받을 수 있고, 제외 사유 파일에 제외 3행의 행 번호·사유·원본 값이 있다. |
| 저장 | 검사한 뒤 페이지를 새로 열어도 마지막 검사 결과가 화면 ②에 남아 있다. |
| 백업 | JSON 백업을 내보낸 뒤 가져오면 같은 검사 결과가 화면 ②에 보인다. 형식이 맞지 않는 파일을 가져오면 가져오지 않고 안내가 보인다. |
| 오류 안내 | `집행금액` 열이 없는 CSV를 넣으면 안내가 보이고 총액은 나오지 않는다. |

## 범위 밖
- localStorage 키를 두 개 이상 쓰는 것
- CSV 붙여 넣기·직접 입력(다음 버전)
- 정상 기준 바꾸기(화면에 고정)
